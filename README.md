<h1>Oxia Chaos</h1>

<p>
  Oxia Chaos runs real Oxia use cases in fault-injected environments. It drives
  workloads through supported SDKs, introduces controlled failures, and verifies
  data safety and recovery across Oxia server versions.
</p>
